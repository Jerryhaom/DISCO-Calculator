How it works: DISCO quantifies how much one person's biomarker profile perturbs the correlation structure of a young, healthy reference population. It is computed from a standard reference matrix (mean vector, cross-product matrix, and age weights), so no individual-level reference data is required — you only need your own biomarker values.

Inputs: enter biomarkers in the listed units. CRP is entered as raw mg/L and log-transformed (log(CRP+1)) automatically.

Interpretation: higher DISCO = greater homeostatic dysregulation. Because absolute DISCO is cohort-specific (population structure + assay calibration), we also report a cohort-adjusted z-score and percentile relative to the selected reference cohort. In validation cohorts (UK Biobank, NHANES, CHARLS, CLHLS, RuLAS) elevated DISCO predicts mortality and chronic disease incidence, and this standard reference matrix preserves 96–97% of predictive power across cohorts.
