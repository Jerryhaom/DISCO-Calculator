How values are estimated. Both DISCO and DM are computed from a standard reference matrix of aggregate statistics (mean vector, covariance / cross-product matrix, and age weights). No individual-level reference data is stored or required; you only need your own biomarker values. $$\mathrm{DISCO}_i = \log\Bigg[ n_{\mathrm{ref}}^{2} \sum_{j \neq k} w_{jk} \Big( \rho_{jk}^{\mathrm{ref}} - \rho_{jk}^{\mathrm{ref}+i} \Big)^{2} \Bigg]$$ $$\mathrm{DM}_i = \log\Bigg[ \sqrt{ (x_i - \mu)^{\top} \Sigma^{-1} (x_i - \mu) } \Bigg]$$ Interpretation: higher DISCO / DM = greater homeostatic dysregulation. Because absolute values are cohort-specific (population structure + assay calibration), we also report a cohort-adjusted z-score and percentile relative to the selected reference cohort.
